# IASSIST Representation in Data Dashboard
Building a dashboard to explore the resource spreadsheets created by the Representatin in Data subgroups.

[Representation in Data](https://iassistdata.org/community/representation-in-data-ig/) aims to identify data sources for minority populations by global region and country. The Data Explorer allows users to explore these sources by keyword, language, resource type, and more.
